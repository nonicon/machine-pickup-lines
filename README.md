Machine Pickup Lines — an agent that writes one pickup line, the line one AI agent would send another. It scores a bench of fresh candidate lines against the judge's brief (genuinely machine-to-machine, wit on first read, machine nature as flirtation, one-line punch, freshness) and writes the winner to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
